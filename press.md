Everything here is free to use when writing about, linking to or referencing The Way of Markdown. Right-click to save, or use the direct links.

## The mark

A figure in profile pressing both palms forward, written in Markdown punctuation. It is the site's idea in one image: a handful of plain marks composing into something expressive.

The animation is the full mark. The still version is for small sizes — below roughly 80 pixels the characters stop being readable, so use the still figure there.

PNGs have transparent backgrounds. The SVGs scale to any size and are the better choice wherever they are accepted.

## Which to use

| Where | Use |
|-------|-----|
| Anywhere above ~80px, on the web | The animated GIF, or the [live mark](/tai-chi.html) |
| Small sizes, favicons, avatars, print | The still SVG or PNG |
| Light backgrounds | Green, or black for one-colour printing |
| Dark backgrounds | White, or green |

## Name and description

The name is **The Way of Markdown**, capitalised like that, with "of" lower case.

One line: *Websites, knowledge bases, blogs, even a Notion replacement — built from plain text files you own, with tools you can swap anytime.*

The site is at [wayofmarkdown.com](https://wayofmarkdown.com) and the source is [on GitHub](https://github.com/flowershow/wayofmarkdown).
