# Markdown Editors

If you want to work directly with Markdown files, these are three editors worth a look. The right choice depends on whether you want a collaborative document editor, a personal knowledge base, or a lightweight writing tool.

- [Colibri](https://www.get-colibri.com/) — a collaborative Markdown editor for GitHub repositories. It brings a Google Docs-style editing experience to a Markdown workflow. Colibri launched in 2026 and is proprietary software.
- [Obsidian](https://obsidian.md/) — a local-first knowledge base for writing and linking Markdown notes. It is a good fit when your files and connections matter as much as the editor itself.
- [Jotbird](https://jotbird.com/) — a lightweight Markdown writing tool.

For the bigger picture, see [how Markdown works across apps and workflows](../everywhere.md).
