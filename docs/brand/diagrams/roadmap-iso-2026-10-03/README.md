# Roadmap, isometric version (2026-10-03)

Backup of the roadmap drawn in the anatomy (isometric) mode: stages as plates, branches as leader labels. Rufus liked it as the simplest version. It was replaced the same day because it lost the branching (see docs/brand/diagram-language.md, "map" mode). To bring it back: copy `roadmap-gen.py` and `isokit.py` over the ones in `scripts/` and run `python3 scripts/roadmap-gen.py`. `roadmap-iso.svg` is the rendered output.
