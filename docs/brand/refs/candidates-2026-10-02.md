# Reference candidates found 2026-10-02 (research agent), for Rufus to tick or cross

Filtered against his taste: likes makingsoftware, code.storage, Co-Star, cosmos.so, Wikimedia header. Dislikes raw plain HTML, corporate dark SaaS, bland product sites, over-busy. Ciechanowski removed (he called it ugly).

## Docs sites
- Stripe Docs — https://docs.stripe.com/ — the benchmark: light, three-column, inline diagrams, code beside prose, never busy.
- Linear Docs — https://linear.app/docs — spare and airy; one idea per screen, generous margins, quiet type.
- Apple Human Interface Guidelines — https://developer.apple.com/design/human-interface-guidelines — light, big calm headlines, flat explanatory illustrations.
- Raycast Manual — https://manual.raycast.com/ — a real "manual": light, screenshot-led, friendly.
- Tailwind CSS Docs — https://tailwindcss.com/docs — elegant type, live examples as figures, restrained colour on white.
- Teenage Engineering Guides — https://teenage.engineering/guides — Swiss technical-manual aesthetic: mono caps, grids, product line drawings.

## Explainer and visual-essay sites
- Red Blob Games — https://www.redblobgames.com/ — light, hand-built diagrams you can poke.
- Ink & Switch — https://www.inkandswitch.com/ — research essays: serif, paper-light, careful figures, ground-up explanation.
- Distill — https://distill.pub/ — academic serif, numbered figures, light; archived but still the model.
- Maggie Appleton — https://maggieappleton.com/ — illustrated essays, warm paper tones, line drawings carry the argument.
- The Pudding — https://pudding.cool/ — editorial visual essays; light, playful, data as illustration.
- Josh W. Comeau — https://www.joshwcomeau.com/ — interactive explainers; whimsical, diagrams genuinely teach.

## Out of the ordinary
- Stripe Press — https://press.stripe.com/ — one light screen, a 3D bookshelf, serif; air with a single idea.
- Devouring Details (Rauno Freiberg) — https://devouringdetails.com/ — paper-light interaction-design textbook; cosmos.so air with worked examples.
- US Graphics (ex Berkeley Graphics) — https://usgraphics.com/ — dotted grid, mono caps, Swiss technical drawings.
- Byrne's Euclid (Nicholas Rougeux) — https://www.c82.net/euclid/ — flat colour geometry diagrams, serif, one proposition per screen.
- Andy Matuschak's Notes — https://notes.andymatuschak.org/ — light, sliding-pane notes; reads like a mind.
- Sketchplanations — https://sketchplanations.com/ — one hand-drawn explanation per screen, flat colour, white space.
