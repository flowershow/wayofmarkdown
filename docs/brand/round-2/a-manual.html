Why

How it ate the world.

It started as a shortcut for web text boxes. People could write it by hand, so tools took it as their format. Tools took it, so more people wrote it. That loop ran for twenty years, and the tools got good. AI arrived late and speaks it by default.

The result: most of what you do in Notion, Google Docs or WordPress, you can now do with markdown tools, combined how you like, keeping the files.

FIG.004 · WHY IT WORKS

Easy, open, extensible.

Easy enough to write by hand. Open, so nobody controls it. Extensible, so it grows from a note to a site to a database without changing format. Few formats sit in the middle of those three. This one does.
