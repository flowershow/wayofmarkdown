# Plan: v0.2 — launch, grow, measure

Created 2026-07-18. Status: **active**. Canonical tracker: the v0.2 epic issue. Predecessor: [[v0.1]] (goals met: polished site, IA, migrations, ~80 pages, visual roadmap, brand, launch kit staged).

## Goals

1. **Launch and measure.** Execute the launch kit (docs/launch/) when Rufus's window opens: Search Console ✅, then HN, Reddit, social, personal network. Analytics live (GA4). Interviews sent the week after. Then: iterate content from actual query/traffic data instead of guesses.
2. **Growth content.** Comparison series (Notion ✅; candidates: markdown vs rich text/Word, Confluence, Evernote — highest-intent SEO genre). Everywhere P2 spokes (Substack, Gmail, Word, Confluence, Bear/iA, VS Code, converter pages). Badge adoption push. Interview series publishing as it lands.
3. **Interactive layer v2.** Roadmap progress-ticking (localStorage; raw-HTML page or Flowershow JS options). Playground niceties (permalink/share, copy button). Possible per-track sub-maps.
4. **Community loops.** Giscus app installed; verify comments live, then seed Discussions. "Who's flying it" badge list. First outside contributions welcomed via good CONTRIBUTING signals.
5. **Carryovers from v0.1.** Tutorial 4 finish-or-restructure (#53 — nb it's Flowershow-specific; may become a lighter "customising your site" guide). Flowershow notes/ review (#50). Other-repos import (#51 — still awaiting list). Sidebar ordering (needs Flowershow-side feature; consider upstream request). OG cards premium check.

## Metrics that matter

Search Console impressions/clicks and which queries; referring domains; HN/Reddit reception; Discussions/comments activity; badge adopters. Reviewed at each planning session; content priorities follow the data.

## Working conventions

Unchanged from v0.1 (see AGENTS.md): epic + sub-issues closed with writeups, inbox #45, review log #57, act-first, voice profile + lint on all prose.

Wrote up what the effort achieved and what was learned across eight versions at the top of [[2026-08-02-markdown-tai-chi-design]]. Homepage integration is the remaining piece.
